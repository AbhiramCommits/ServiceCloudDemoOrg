# Value Model — Northwind Outfitters Support PoC

This document shows the arithmetic from the **measured simulation output** to an annualized business
value. Every input is a number produced by running code in this repo, and each one cites the file it
comes from. No figure here is invented or assumed beyond the explicitly stated assumptions.

## Assumptions (stated explicitly)

- **A1.** Fully-loaded support agent cost = **$38.00 / hour**. Configured once in
  `sim/config.py` (`LOADED_AGENT_COST_PER_HOUR`).
- **A2.** A deflected request consumes **zero** human handling time. (The assistant answers it end to
  end; this is the definition of "deflected" used throughout the harness.)
- **A3.** An agent works **8 hours × 21 days = 168 hours / month** (`sim/config.py`).
- **A4.** The dataset is synthetic but Northwind-scale: 4,000 requests / month, 12 agents, one month
  (30 days) — matching the numbers Dana gave in `docs/discovery-brief.md`.
- **A5.** Saved minutes are valued at the loaded hourly cost of the work they release. The PoC does
  **not** assume headcount reduction; freed capacity is treated as headroom.

## 1. Deflection: handling time removed

Deflected requests no longer reach an agent at all. The harness measures how many baseline handling
minutes that removes:

```
deflected requests / month            = 2,278
baseline handling minutes per request = 15.18 min   (includes P1 rework + P5 manual warranty lookup)
agent-hours freed / month             = 592.58 h    (measured, results/metrics.json)
agent-hours freed / year              = 592.58 × 12 = 7,110.96 h
annual labour value                   = 7,110.96 h × $38.00/h = $270,216.48
```

- **Monthly value:** 592.58 h × $38.00 = **$22,518.04**
- **Annual value:** **$270,216.48**

## 2. Capacity freed, expressed in agents

Same hours, expressed as agent-equivalents so a hiring plan can be read off directly:

```
agent-equivalents freed = 592.58 h/month ÷ 168 h/agent-month = 3.53 agents' worth of work
cost of 3.53 agents      = 3.53 × (168 h × $38.00) = 3.53 × $6,384 = $22,535 / month
```

This cross-checks the hours-based figure ($22,518 vs $22,535 — a rounding difference). It is headroom,
not a layoff: the same 12 agents now absorb a growing order book instead of a growing inbox.

## 3. Human-handled load per agent

```
baseline   : 4,000 handled ÷ (12 agents × 21 days) = 15.87 cases/agent/day
Salesforce : 1,722 handled ÷ (12 agents × 21 days) =  6.83 cases/agent/day
reduction  : 9.04 cases/agent/day (−57.0%)
```

Each remaining human case is also cheaper: automated warranty eligibility (P5) and the removal of
duplicate work (P1) strip ~7 minutes of manual lookup and re-typing from the baseline 15.18 minutes.

## 4. SLA and responsiveness (risk reduction, not priced)

```
SLA breaches / month : 2,274 → 108   (−2,166; −95.3%)
SLA compliance       : 43.15% → 97.30%
first response mean  : 575.83 → 80.54 min   (9.60 h → 1.34 h; target was < 2 h)
first response p90   : 1,293.65 → 241.24 min
backlog age          : 33.81 h → 3.10 h
```

The discovery brief attributed **$34K/year at risk** to slow handling of high-value customers (P2).
This model does **not** claim that value, because the harness measures response time, not churn. It
reports the SLA improvement as measured and leaves retention value to the customer's own model.

## Bottom line

| Component | Monthly | Annual | Basis |
| --- | ---: | ---: | --- |
| Handling time removed by deflection | $22,518.04 | **$270,216.48** | measured hours × A1 |
| SLA breaches avoided | 2,166 | 25,992 | measured, not priced |
| Human-handled load reduction | 9.04 / agent / day | — | measured |
| First response | 1.34 h mean | — | measured |

The one headline dollar figure this model defends is **$270,216.48 per year** in agent time released
by deflection, on a dataset that matches the customer's stated volume. Every input is reproducible
with `make all` and traceable to `results/metrics.json`.
